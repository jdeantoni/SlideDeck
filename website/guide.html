DOCUMENTATION / GETTING STARTED

Your first SlideDeck.

From an idea to an HTML presentation, one step at a time.

01

Install from source

You'll need Node.js 16 or newer, npm and Git. Clone the repository, install its dependencies, generate the parser, and build:

git clone https://github.com/jdeantoni/SlideDeck.git
cd SlideDeck
npm install
npm run langium:generate
npm run build
02

Write your slides

Create a file named talk.slidedeck. Separate slides with ===:

{
  author: "Your Name"
  title: "My Presentation"
}
===
# Hello, SlideDeck
Your first slide.
===
## What's next?
- Write in **bold** and *italic*
- Share your ideas

Existing .sdml files are supported too.

03

Generate your presentation

Run the compiler and open the resulting HTML in a browser:

node out/cli/main.js compile talk.slidedeck -o talk.html

Generated presentations load reveal.js and other libraries from CDNs, so internet access may be required.

04

Preview as you work

Start the browser editor and live preview:

npm run dev talk.slidedeck

Or use the VS Code extension to edit and preview side by side. Install a packaged extension or launch it from source with F5, then run SlideDeck: Open Preview to the Side. See the VS Code instructions for details.

05

Keep exploring

Discover styled blocks, fragments, notes, drawings and interactive editors in the full documentation.
