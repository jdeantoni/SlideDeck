DOCUMENTATION / EXAMPLES

Learn by doing.

Small examples, ready to copy into a .slidedeck file.

Each SlideDeck example below is a complete presentation. Save it as talk.slidedeck, then compile or preview it using the getting-started guide. Use the copy button, or select the text manually. Read the notes for assets, internet access and other prerequisites.

New to SlideDeck? Build one presentation step by step before exploring these examples.

Slides and text

Metadata, headings and formatting

Metadata is optional; when present, put author then title first. Separate slides with ===. Use up to three heading levels.

{
  author: "Ada"
  title: "My first deck"
  theme: "white"
}
===
# Welcome
This is **bold**, *italic*, and __underlined__.
===
## Next slide
### A smaller heading
// This comment is not shown

Comments can also use /* ... */ across multiple lines. Put comments on separate lines; inline comment markers in slide text remain visible.

Lists and quotes

Indent a child marker at least to the start of its parent's text. List items are single-line.

# Things to do
- Plan
  - Gather ideas
  - Make a draft
1. Rehearse
2. Present
> Keep the message clear.

Links and QR codes

Links use ![label] "destination"; images use parentheses instead. The special QR label generates an image from an online QR service.

# Find out more
Read ![the SlideDeck repository] "https://github.com/jdeantoni/SlideDeck".
![QR] "https://github.com/jdeantoni/SlideDeck"

Links can also use mailto:, relative paths or fragments. Check relative links in the generated HTML.

Inline styles, notes and footnotes

Use an inline span for part of a line. Hover notes use the browser's native tooltip and may not be accessible to keyboard or touch users.

# Explain a concept
This is [important]{color: 'red'; font-weight: 'bold'}.
[Hover here]{note: 'More context'} for a note.
[*A term*]{footnote: ['A styled explanation']{color: 'blue'}}

Footnotes appear at the end of the slide, even if their reference is inside an unrevealed fragment. Inline styles apply to a span, not to the containing list item.

Styles and layout

Styled blocks and list width

Block styles use CSS properties. Set a container width to constrain a whole list.

# A compact list
::: {width: '50%'; margin: '0 auto'; color: 'teal'}
- First point
- A longer point that wraps within the container
:::

Use a class such as .callout in a block or inline span and define it in the metadata css field:

{
  author: "Ada"
  title: "Classes"
  css: ".reveal .callout { color: teal; }"
}
===
# Reusable styles
::: {.callout}
This block uses a class.
:::
This [word]{.callout} uses it too.

columns and gap create a grid of individual children. Use :::: with nested ::: blocks to group multiple elements in each column.

Positioning and transforms

horizontal-margin and vertical-margin position in pixels; calque sets the layer. Transform shortcuts include rotate, scale, translate-x, translate-y and skew.

# Place an element
::: {horizontal-margin: 100; vertical-margin: 200; calque: 2; rotate: -5}
Positioned and rotated
:::

Images and video

Paste an image in VS Code

With VS Code 1.97 or later, save your SlideDeck file, copy an image or image file, and paste it into the SlideDeck editor with Ctrl+V (or Cmd+V on macOS). The extension stores a copy in an img folder beside the source and inserts a reference such as ![Image](./img/image-unique-name.png). Keep that folder with your source file. See the step-by-step guide.

Use an existing image

For this example, put talk.slidedeck in the repository root: the image path points to an image included in the repository. If you installed the extension without cloning the repository, replace the path with your own image or URL.

# An image
![Logo](examples/templates/template2/assets/image_logo.png){offset: '20px 10px'}{size: '250px 100px'}

Image dimensions and offsets are in slide pixels. Images are embedded during compilation. For local video, use the same syntax with a video file; the compiler copies it into an assets folder beside the HTML.

# A YouTube video
![Video](https://www.youtube.com/watch?v=dQw4w9WgXcQ)

YouTube playback requires a network connection and permission from the video provider.

This local-video example also assumes the source file is in the repository root. If you installed the extension without cloning the repository, replace the path with your own video.

Code and math

Syntax highlighting and progressive steps

Specify the language and optional highlight mode in the opening fence. Modes include all, none, line-by-line, block, function and class. Advance through line-by-line highlights using the presentation controls.

# Code
```javascript [highlight:line-by-line]
const x = 2;
console.log(x);
```

Synchronized fragments

Use [---] between explanations. Add keep after sync-fragments to accumulate them rather than replace them.

# Explain code
```javascript [highlight:line-by-line]
let x = 1;
x += 2;
```
:::[sync-fragments]
Start at one
[---]
Add two
:::[sync-fragments]

Mathematics

Write inline math between dollar signs and use a latex code block for display math. Include a LaTeX block in the presentation to enable math rendering; it loads KaTeX from a CDN.

# Mathematics
Inline: $E = mc^2$
```latex
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
```

Fragments and transitions

Advance to reveal each fragment. Use index: 0 inside the fragment attributes to control ordering. The presentation-wide transition belongs in metadata; a slide can override it at its start.

  transition: "none"
}

First idea

::: {animate: "fade-in"}

Interactive content

Embedded code editor

Connect an editor to an output by using the same quoted ID. Supported languages are javascript, python and sql. Monaco and execution runtimes require internet access.


Live quiz

Start the quiz server from the project root with npm run quiz-server. It listens on port 4433. Serve the generated presentation over HTTP using a hostname reachable by participants; the quiz connects to that same hostname on port 4433. Opening the HTML directly as a file is not suitable for a shared quiz. See the quiz setup instructions.

:::quiz
"Quick quiz"
showJoinQrCode: true
question: "Which number is even?"
choice "one": "1"
choice "two": "2"
correct: "two"
showResultsOnDemand: true
visualization: barChart
:::

Drawing and visual layout

Presentation chalkboard

Press C for the slide notes canvas or B for the chalkboard; D downloads drawings. This plugin is separate from preview drawings and loads online.

{
  author: "Ada"
  title: "Draw while presenting"
  chalkboard: "true"
}
===
# Draw on this slide

VS Code preview: move, resize and save drawings

Open the native preview in a trusted workspace. Select Edit layout to drag images or styled blocks; select an image and drag its corner to resize it. Shift preserves proportions while resizing. Draw lets you create pen strokes, arrows, rectangles and ellipses; Save fragments stores each as an SVG and a fragment in the source.

In layout mode drag the visible bounds of a saved drawing or its corner to move or resize it. These are whole-image transforms, not arrow endpoint editing. Save the source file to retain changes. Undo does not delete generated SVG files. Presentation-time dragging is not supported. The preview follows the editor's current slide; double-click non-interactive slide content to return to its source.

Themes and templates

Select a reveal.js theme through metadata. Starter decks for academic, business, conference, technical and minimal layouts are available in the template directory; copy one as the basis for a presentation.
